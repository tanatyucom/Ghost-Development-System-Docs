# Missing Input Classification Standard

**Version:** 1.0
**Status:** Adopted

| Class | Examples | Draft result |
| --- | --- | --- |
| Non-blocking | optional notes/example/tool, formatting preference | Draft Ready + warning |
| Prompt-required | multiple safe repositories/titles/paths, language or timing choice | Review Required + minimal question |
| Blocking | repository identity/root for mutation, authority, approval scope, security boundary, critical dependency | Incomplete + execution NONE |

Missing data is not conflict. Conflict follows precedence and invalidation; an
unresolved Critical conflict produces SCW. Every missing input records field,
class, reason, known context, owner, resolution method, and resume condition.
