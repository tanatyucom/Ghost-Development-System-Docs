# Generated Draft Safety Rules

**Version:** 1.0
**Status:** Adopted

- Every generated Q is Draft with Execution Authority NONE.
- Approval Status is NOT APPROVED; Startup and mutation are NOT PERMITTED.
- Source Completion PASS is not next-Q approval.
- Registry Mutation Class is not Q Mutation Authority.
- Planned/Pending repositories are not execution targets.
- Critical missing values remain unresolved and visible.
- Known fresh context is inherited with provenance and not asked again.
- Workspace, branch divergence, credentials, locks, external state, and dirty
  files require current revalidation and are not inherited as current truth.
- Safe correction must be unique, bounded, recorded, and authority-neutral.
- Human Approval never bypasses subsequent Startup verification.
